# MetalVJ-Experimental

Visual design tool for musical reactivity. AGPL-3.0.

A pre-alpha build: rendering is proven and stable, and the tool is considered a
minimum viable product without the actual weights of the AI. It is an
experiment — shown as a working pre-alpha, not a finished product.

It uses the modern language Rust to achieve a high standard of quality, and is
free and open source. It runs physics and math simulations as efficient small
models of AI that run on the GPU, locally.

A native desktop program, it runs locally on your CPU and GPU, and also ships a
built-in MCP interface for easy integration with AI assistants.

It is strong and local, but also integrates with external LLM APIs like Claude
Code or any AI agent. The harness engineering is designed for an AI that helps
make stunning visuals of any type.

The AI drives the same tools you would use for the loops of a screen in
corporate events or imposing visuals at a rave — all on demand of prompts, and
ready for use.

DMX output for controlling all sorts of fixtures, authored by custom small AI
models.

## What it does

- Write new custom shaders.
- Import your logos and texts.
- A timeline for sequential media.
- Manage animations by dragging nodes.
- Use, customize and nest effects.
- Create assets from scratch.
- Sync with other software.
- Control pixel outputs and light fixtures.
- Render using WGPU.
- Make the software evolve for your needs, because it is open.

Deploy for free, even for commercial purposes.

Open Source Software for live-event producers.

**Free and Open Technology Means for Artists.**
